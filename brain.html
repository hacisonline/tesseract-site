One grounded path

From request
to answer.

Brain is part of a governed building system. It receives grounded context after identity and retrieval have determined what the request is allowed to see.

01 / REQUEST

Person

A resident or building-team request begins on an authorised surface.

02 / ACCESS

Identity Gate

The request is bound to the person and the units they are allowed to access.

03 / CONTEXT

The Twin

The building's living model supplies the relevant records and operating context.

04 / EVIDENCE

Grounding

Retrieval comes first; below the evidence threshold, the system returns an honest miss.

05 / INFERENCE

Brain

The local model forms an answer over the grounded context and returns it to the person.
